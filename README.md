# Assembly-ის სასწავლო გზამკვლევი (4 კვირა)

**სამიზნე აუდიტორია:** დამწყები, რომელსაც აქვს პროგრამირების საბაზისო გამოცდილება
(სასურველია C# ან სხვა მაღალი დონის ენა), მაგრამ არ იცნობს Assembly-ს.

**არჩევანი:** x86-64, NASM სინტაქსი (Intel), Linux (WSL2 ან native).

---

## 🎯 რას ისწავლი 4 კვირაში

| კვირა | თემა                                                    | შედეგი                                 |
| ----- | ------------------------------------------------------- | -------------------------------------- |
| I     | CPU, რეგისტრები, არითმეტიკა, მეხსიერება, ციკლები        | დაწერ პატარა პროგრამებს `syscall`-ებით |
| II    | Stack, ფუნქციები, calling convention, ბიტური ოპერაციები | ააგებ კალკულატორს                      |
| III   | C ↔ Assembly, struct-ები, SIMD, debugging               | asm ფუნქცია C-დან გამოიძახე            |
| IV    | Buffer overflow, Reverse engineering, .NET JIT          | crackme-ს ამოხსნი, JIT asm-ს ნახავ     |

---

## ✅ წინაპირობები (Prerequisites)

**აუცილებელი:**

- Linux სისტემა (ან WSL2, ან Docker, ან VM)
- ტერმინალის საბაზისო გამოყენება (`cd`, `ls`, `cat`, pipe)
- 1-ლი კვირისთვის: არაფერი Assembly-ის
- 2-ლი კვირიდან: მასივები, ციკლები, ფუნქციები რომელიმე ენაზე

**სასურველი (მაგრამ არა სავალდებულო):**

- C-ის საბაზისო ცოდნა (III კვირისთვის)
- hex ↔ decimal კონვერტაცია თავში

**არ გჭირდება:**

- წინა Assembly გამოცდილება
- რთული მათემატიკა
- Hardware-ის ცოდნა

./test-env/verify.sh
./test-env/run-tests.sh
